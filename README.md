# whiteboard
Un tableau défouloir pour les copaings, parce qu'il faut bien décompresser des projets sans méthode Agile, sans sprints, et sans longues réunions 

# Quelques règles 
Ne supprimez pas l'existant sans l'accord de l'auteur, sauf si quelqu'un a push quelque chose qui casse ce que vous vous avez fait !!!

# Quelques conseils
Isolez de préference ce que vous faites dans une div indépendante, après si c'est + drôle sans la div, pourquoi pas !!
Niveau style, vous pouvez nommer vos classe en mettant votre nom, type p1-eni etc etc, comme ça on se chevauche pas 
N'hésitez pas à demander à vos pairs des conseils sur votre code, ça peut être sympa de justement évoluer dans ce sens
